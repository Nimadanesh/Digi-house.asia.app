# Agent Handoff Protocol

A handoff must preserve context without making the next agent rediscover the work.

## Required handoff
```text
Goal:
Scope:
What changed:
What did not change:
Evidence / decisions:
Verification:
Known blockers:
Next action:
```

## Rules
- Do not hand off unresolved assumptions as facts.
- Link to the relevant repository document or file path when possible.
- Keep the next action concrete and minimal.
- If work is blocked, state the exact missing prerequisite.
