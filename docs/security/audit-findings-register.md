---

## Column definitions

| Column | Description |
|---|---|
| **ID** | `AUD-<n>` — sequential, never reused |
| **Severity** | C / H / M / L / Info |
| **Title** | One-line summary |
| **Contract** | Affected contract file or module |
| **Status** | Open / Fixing / Fixed / Accepted / Duplicate / Not Applicable |
| **Owner** | Engineer responsible |
| **PR** | Link to fix PR |
| **Retest** | Auditor retest result (PASS / FAIL / Not Yet Tested) |
