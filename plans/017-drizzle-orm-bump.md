## Why this matters

`npm audit` flags `drizzle-orm <0.45.2` with a **high**-severity advisory
(improper escaping of identifiers used in dynamically-built queries). Installed
is `drizzle-orm@0.44.x`, and every API DB route goes through it
(`apps/api/src/db/client.ts` creates the Drizzle client; all stores use it).
The fixed line is a released minor (`0.45.x`), so this is a framework-version
maintenance task, not a rewrite. The API has a full vitest suite using
in-memory stores plus a `db:migrate` path that must be re-validated.

## Scope

**In scope**:
- `apps/api/package.json` and the root `package-lock.json` (via the install)
- `apps/api/drizzle/**` — re-generated migration files ONLY if `drizzle-kit generate` reports schema drift after the bump
- `apps/api/src/**` — only if the bump forces a mechanical API fix (e.g. a renamed type); that must be a named, minimal change, not a refactor

**Out of scope** (do NOT touch):
- Any runtime query behavior changes — the upgrade must be behavior-preserving.
- `drizzle-kit` version (leave at `^0.31.0` unless the new ORM forces it; if it does, STOP and report).
- Frontend (`src/**`) and `packages/**`.
- Database data or schema semantics.

## Steps

Run `npm install drizzle-orm@^0.45.0 --workspace apps/api` from the repo root,
then `npm run typecheck:api`.

**Verify**: `npm run typecheck:api` exits 0. If it fails, inspect errors —

**Verify**:
