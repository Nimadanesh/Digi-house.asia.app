# How does a property appear in the marketplace?

**Q:** How does a property appear in the marketplace?

**A:** Each of the 24 estates appears as a card with price (or last price on
resale), projected income per share, ownership fraction ("1 share ≈ 1/N of the
estate"), and — on primary offerings only — availability ("X% funded · N shares
remaining" + bar). Tapping a card opens that villa's page (`action.open-estate`).
Availability figures are live data, never static claims.
