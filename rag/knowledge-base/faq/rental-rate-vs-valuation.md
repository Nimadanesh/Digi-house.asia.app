# What is the difference between rental rate and valuation?

**Q:** What is the difference between rental rate and valuation?

**A:** They measure two completely different things.

**Rental rate (ANR)** tells you the average nightly price at which the villa is listed for full buyout. It is used as an input when rental income is modeled.

**Valuation** is the reference value assigned to the whole villa. It is used when the app describes the estate's value and related share information.

So, in simple terms:

**Rental rate → helps model rental income.**

**Valuation → describes the value of the estate.**

One does not tell you the other.
