# سبد دارایی‌ام را کجا ببینم؟


# Portfolio را کجا ببینم؟

**سؤال:** Portfolio من کجاست؟

**پاسخ:** وارد تب **Portfolio** شوید. این بخش نمای اصلی شما از چیزهایی است که در اختیار دارید و وضعیت موقعیت‌های شماست.

Portfolio می‌تواند شامل این موارد باشد:
- Shareهای شما و تعداد آن‌ها؛
- ارزش نمایش‌داده‌شده؛
- سود یا زیان نسبت به زمان خرید؛
- نحوه‌ی توزیع دارایی بین Estateها؛
- سفارش‌های باز که هنوز تکمیل نشده‌اند.

**Open Order** یعنی سفارشی که هنوز منتظر سفارش مقابل است؛ بنابراین با معامله‌ی تکمیل‌شده یکی نیست. اگر امکان لغو وجود داشته باشد، سفارش قبل از تکمیل قابل لغو است.

**قدم بعدی:** وارد **Portfolio** شوید تا اطلاعات فعلی حساب خود را ببینید.
