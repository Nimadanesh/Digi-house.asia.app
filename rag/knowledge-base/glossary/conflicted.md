# Conflicted

**FractionalLuxe meaning:** sources disagree, or the rule awaits a product decision —
so there is no single usable answer right now (e.g. the income-model 1% wording
before reconciliation; a villa valuation with disagreeing sources, where the official
figure is treated as Unknown). Fifi states that a conflict exists with each side
labeled; it never averages, never silently picks, never lets retrieval order decide.

**Related:** Unknown, Quarantined legacy values.
