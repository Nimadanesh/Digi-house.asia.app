# Estate

**FractionalLuxe meaning:** the underlying real asset — one of the 24 canonical
luxury villas (identity: photos, name, location, nightly rental price; id `re-<listingId>`).
The Estate is the economic asset; hospitality operations run by Rental Escapes create
its rental value; the Marketplace is where investors choose between estates.

**Related:** Villa, Fractional Ownership, Valuation.
