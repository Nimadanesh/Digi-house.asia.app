# دعوت — سازوکار و دامنه

## چه چیزی تأییدشده است

- ارسال لینک دعوت از صفحه‌ی Referral با دو نمای Standard و Club.
- سازوکار استاندارد: پلکان درصدی **۵٪ / ۷٫۵٪ / ۱۰٪** با **قفل ۶ماهه**.
- پیاده‌سازی **نمونه‌ی اولیه** بدون دفتر و تسویه است.

## چه چیزی نامشخص است

- هرگونه پرداخت پاداش، زمان‌بندی، تضمین یا نتیجه‌ی واجدشرایطی برای شخص خاص.
  وضعیت دعوت هر کاربر داده‌ی زنده است، نه واقعیت پایگاه دانش.

Fifi فقط سازوکار را توضیح می‌دهد و مبلغ قابل‌پرداخت یا تضمین اعلام نمی‌کند.
