# Missing Data and Pending States

## What does Pending or Unknown mean?

When a field shows **Pending**, **Data pending**, or **Unknown**, the product does not currently have verified information for that field.

It is not the same as zero. It also does not mean that a hidden estimate exists.

For example, occupancy is currently unavailable as a verified figure for the canonical villas. The app should leave it pending rather than invent an occupancy percentage.

## Why would a field be missing?

A property may have a specification, document, or other fact that has not yet been verified or is not available in the current product data.

This is deliberate: an honest missing value is more useful than a made-up precise value.

## What should I do?

If the missing information does not prevent you from exploring the property, you can continue using the available information.

If it prevents you from completing an important action or understanding a required document, use the app's support path. Fifi can explain what the field means, but should never manufacture the missing value.
