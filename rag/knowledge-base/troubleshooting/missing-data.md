# Missing data and pending states

**Symptom:** a field shows pending, "Data pending", or "Unknown".

**Verified guidance:**
- This is intentional honesty, not a bug: fields without verified data (occupancy for
  all villas, unsourced specs, unavailable documents) render pending/Unknown rather
  than guessed numbers.
- "Data pending" chips on estate cards, pending rows in specs, and honest empty
  states are the correct display. Do not treat them as errors to work around.
- If the missing item blocks the user (e.g. a needed document), the path is the app's
  support channel — Fifi must not fill the gap.

**Do not invent** the missing value under any circumstance.
